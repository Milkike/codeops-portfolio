# Addis Eats

A static food menu built with React and Vite as part of IBT College Toronto CodeOps — Day 26.

## Features

- React functional components
- JSX
- Props
- Component composition
- Array rendering with `map()`
- Unique keys for list items
- Reusable `Dish` component

## Components

### App
The root component that composes the application.

### Header
Displays the Addis Eats title and description.

### Dish
A reusable component that receives `name` and `price` as props.
